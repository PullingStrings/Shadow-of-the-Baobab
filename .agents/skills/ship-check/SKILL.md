# ship-check

Check user journey, key tests, accessibility/performance for relevant UI, secrets, configuration and deploy readiness. Do not deploy without approval. Update `docs/STATE.md` with touched files, exact commands/results, blocked tasks, and one next action. Report caveats honestly.
