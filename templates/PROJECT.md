# Project brief

- **Outcome**: What should users be able to do?
- **Target audience**: Who is it for?
- **First vertical slice**: The smallest end-to-end experience that proves value.
- **Acceptance criteria**: Observable, testable behaviours.
- **Constraints**: Timeline, cost, privacy, browsers, deployment, constraints on stack.
- **Chosen architecture**: Record only after assessing requirements and current docs.
- **Non-goals**: What we deliberately won't build this iteration.
- **Verification**: Commands and a real usage scenario.
